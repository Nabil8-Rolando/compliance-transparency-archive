# Employment & Compliance Transparency Archive  
Author: **Nabil Amzil**  
Location: **Laayoune, Morocco**

This repository contains a structured and neutral administrative archive related to my period of employment at Farm 41 (Maraissa / Azura Group) in Dakhla, Morocco.

- Maintain an organized record of official employment documentation.
